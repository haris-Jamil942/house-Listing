# 🏠 House Listing - Real Estate Web Application

A full-stack **House Listing web application** built using the MERN stack. This project allows users to browse, search, and view property listings for rent or sale with a modern and responsive UI.

---

## 🚀 Features

- 🏡 Browse property listings (Rent / Sale)
- 🔍 Search properties by location, price, and type
- 📄 Detailed property information page
- 🖼️ Image gallery for each property
- ❤️ Save / favorite listings (if implemented)
- 👤 User authentication (Login / Register)
- ➕ Add new property listings (if admin/user enabled)
- 📱 Fully responsive design (Mobile, Tablet, Desktop)
- ⚡ Fast and optimized frontend performance
- 🔐 Secure backend APIs with authentication

---

## 🛠️ Tech Stack

### Frontend
- HTML5, CSS3, JavaScript
- Bootstrap / Custom CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB with Mongoose

### Other Tools
- JWT Authentication
- Cloudinary (Image Upload)
